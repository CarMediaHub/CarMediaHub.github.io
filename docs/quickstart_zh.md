# 用户快速开始

CarMediaHub 是用户自行部署的系统。域名、服务器、存储和上游账号由运营者控制，Core 提供统一认证的 Web 入口，用于访问媒体和已安装服务。

## 开始前

- 根据目标环境选择部署方式，并准备独立的数据目录。
- 准备域名和 HTTPS 证书。浏览器能力只允许访问已登记的 HTTPS Origin。
- 先确定需要启用的用户、媒体根目录和插件。

## 首次运行

1. 按目标环境的发布说明安装 Core。
2. 完成初始化引导并创建第一个管理员。
3. 进入管理端，确认语言、时区、安全设置和备份设置。
4. 只安装实际需要的插件和受管基础组件。
5. 添加媒体根目录或远程来源，先验证小文件，再测试大文件播放。
6. 分别从桌面浏览器和车机浏览器打开入口。车机播放会根据媒体能力选择 HLS 或转封装流。

## 安全边界

除非插件文档明确说明了受保护的凭据流程，否则不要把 Cookie、浏览器 Profile、私钥或上游密码粘贴到插件配置中。保持 Core、插件和组件包更新，并在升级前创建可验证的备份。
