# 开发者快速开始

插件是遵循 SDK 契约运行的 Worker。插件应通过 SDK 请求平台能力，不应直接访问 Core 数据库、浏览器上下文、宿主文件系统或组件进程。

## 开发顺序

1. 阅读版本化 SDK 类型和插件契约。
2. 声明稳定的插件 ID、版本、运行时、能力和服务绑定。
3. 使用 SDK 提供的上下文访问语言、身份作用域、显示、历史、媒体、任务和数据能力。
4. 将插件状态放入有作用域的数据 API，并提供版本化迁移。
5. 为能力拒绝、用户隔离、取消和重启补充契约测试。
6. 在发布到目录前完成插件打包和签名。

## 不可突破的边界

- 存在逻辑目标或服务绑定时，不接受原始上游 URL。
- 不返回 Cookie、浏览器 Profile、CDP 端点或宿主路径。
- 不假设特定数据库引擎或操作系统环境变量。
- SDK 下发的语言和显示偏好是平台统一上下文，插件不得要求用户重复设置。
