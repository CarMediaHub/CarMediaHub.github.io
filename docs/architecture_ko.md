# 아키텍처

상태: v0 초안

CarMediaHub는 운영자가 관리하는 인프라를 통해 승인된 로컬 기능을 브라우저와 차량용 디스플레이에 제공하는 자체 호스팅 플랫폼입니다.

```text
브라우저 또는 차량용 디스플레이
  -> 운영자가 관리하는 진입점
  -> CarMediaHub Gateway
  -> Core, Broker, Supervisor
  -> 격리된 플러그인 런타임 그룹
  -> 승인된 로컬 리소스 또는 허용된 네트워크 대상
```

Core는 유일한 공개 애플리케이션 진입점입니다. 플러그인은 논리 경로를 등록하고 SDK capability를 사용하며, 호스트 공개 포트나 원시 데이터베이스 자격 증명, 제한 없는 호스트 경로·브라우저 프로필·네트워크 접근을 받지 않습니다.

## 런타임 그룹

| 그룹 | 용도 |
|---|---|
| 공유 어댑터 호스트 | 위험이 낮고 요청 모델이 호환되는 가벼운 어댑터 |
| 독립 Worker | 브라우저, 파일, 네트워크, 미디어, 서드파티, 장시간 또는 고자원 작업 |
| WASM 모듈 | 임의 시스템 접근과 장기 연결이 없는 순수 계산 |

플러그인 설치가 영구 프로세스를 의미하지는 않습니다. Supervisor가 수명 주기와 리소스 정책에 따라 런타임 그룹을 시작, drain, 중지, 업데이트하고 복구합니다.

## 데이터와 ID

모든 작업은 해당되는 경우 Deployment, Organization, User, Device/Session 및 Plugin Installation 범위를 가집니다. 플랫폼은 논리적으로 격리된 데이터 접근을 제공하며 저장소 백엔드는 공개 SDK 동작을 바꾸지 않습니다.
