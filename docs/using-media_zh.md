# 媒体使用

CarMediaHub 适合分工使用：在电脑上完成媒体源和播放策略配置，再从手机或车机浏览器使用更简单的入口。

## 浏览和播放

从主面板打开已安装的媒体插件，浏览目录或搜索目录，选择支持的媒体并开始播放。媒体源和凭据由 Core 保管，客户端只收到有作用域的播放响应。

车机浏览器优先使用已经支持格式的 Range 直出。当文件需要兼容处理时，插件可以请求 Core 执行受控的转封装或转码任务。结果是短期不透明数据，车机不会获得 FFmpeg 命令、本地路径或上游凭据。

## 车机控制

车机布局应保持导航、搜索、播放/暂停和全屏操作可见，不依赖桌面专用控件。全屏是显示能力，不代表每个浏览器都实现完全相同的 API。如果浏览器不支持全屏或某种播放模式，插件应显示可恢复的状态，并提供其他支持模式。

## 历史和诊断

统一历史服务可以记录有界的播放和导航记录。历史记录按当前用户和插件安装实例隔离，可从管理端搜索或清除。诊断应显示“来源不可用”“播放会话已过期”“缺少媒体模式”等稳定原因，不应泄露上游密码、宿主路径或内部端点。

## 当前限制

手机和车机播放能力取决于浏览器的媒体实现。HLS、转封装和转码是按能力协商的，并不保证每个文件或设备都能播放。出行前应在目标车机上验证有代表性的文件。
