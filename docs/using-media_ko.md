# 미디어 사용

CarMediaHub는 작업을 나누어 사용하는 방식에 맞습니다. 데스크톱에서 미디어 소스와 재생 정책을 설정한 뒤 휴대폰이나 차량 브라우저에서 간단한 진입점을 사용합니다.

## 탐색과 재생

메인 패널에서 설치된 미디어 플러그인을 열고 폴더를 탐색하거나 카탈로그를 검색한 다음 재생을 시작합니다. 미디어 소스와 자격 증명은 Core가 보관하며 클라이언트에는 범위가 지정된 재생 응답만 전달됩니다.

차량 브라우저에서는 지원되는 형식이면 Range 직접 스트림을 우선 사용합니다. 호환 처리가 필요하면 플러그인이 Core 소유 리먹스 또는 트랜스코드 작업을 요청할 수 있습니다. 결과는 단기간 유효한 불투명 값이며 차량 브라우저에는 FFmpeg 명령, 로컬 경로 또는 상위 서비스 자격 증명이 전달되지 않습니다.

## 차량 제어

차량 화면에서는 데스크톱 전용 조작 없이 탐색, 검색, 재생/일시 정지와 전체 화면을 사용할 수 있어야 합니다. 전체 화면은 디스플레이 기능이며 모든 브라우저가 같은 API를 구현한다는 뜻은 아닙니다. 지원되지 않는 경우 복구 가능한 상태와 다른 재생 모드를 표시해야 합니다.

## 기록과 진단

공용 기록 서비스는 제한된 재생 및 탐색 기록을 저장할 수 있습니다. 기록은 현재 사용자와 플러그인 설치 범위로 격리되며 관리 화면에서 검색하거나 삭제할 수 있습니다. 진단에는 소스 불가, 재생 세션 만료, 미디어 모드 부족과 같은 안정적인 이유만 표시하고 비밀번호, 호스트 경로 또는 내부 엔드포인트는 표시하지 않습니다.

## 현재 제한

모바일과 차량 재생은 브라우저의 미디어 구현에 따라 달라집니다. HLS, 리먹스와 트랜스코드는 기능 협상 결과이며 모든 파일이나 장치의 재생을 보장하지 않습니다. 여행 전에 대상 차량에서 대표 파일을 확인하십시오.
