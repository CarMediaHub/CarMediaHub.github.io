# 프로젝트 목표

상태: v0 초안

CarMediaHub의 목표는 운영자가 관리하는 미디어, 내부 서비스와 확장 가능한 어댑터를 브라우저와 차량용 화면에서 사용할 수 있게 하면서 필수 호스팅 릴레이에 의존하지 않는 것입니다.

## 사용자 결과

- 제한된 차량용 브라우저에서 개인 미디어에 접근합니다.
- 모든 내부 포트를 공개하지 않고 저장소와 상류 서비스를 연결합니다.
- 하나의 진입점에서 인증, 기록, 작업과 진단을 사용합니다.
- 플랫폼 컨텍스트, 언어, ID와 capability 제어를 상속하는 플러그인을 설치하거나 개발합니다.
- 도메인, 서버, 대역폭, 데이터와 상류 계정을 운영자가 계속 관리합니다.

## 하나의 웹 화면

CarMediaHub는 서로 관련 없는 여러 사이트가 아니라 하나의 웹 서비스입니다. 패널은 일반 앱 탐색을 제공하거나 특정 앱에 대해 취소 가능한 키 진입점을 제공할 수 있습니다. 내장 관리 앱은 패널에서 플러그인과 같은 수준으로 표시되지만, 복잡한 설정은 운영자가 수행합니다.

데스크톱 브라우저는 설치, 권한, 서비스 연결, 세션 가져오기, 백업과 업데이트에 사용합니다. 휴대폰은 반응형 탐색과 간단한 설정을 제공합니다. 차량용 화면은 간단한 탐색, 검색, 재생, 전체 화면과 복구에 도움이 되는 상태 표시를 우선합니다.

## 플랫폼 목표

Core, Gateway, SDK, 서비스 바인딩과 런타임 격리가 장기 플랫폼 기능입니다. WDR은 중요한 네이티브 미디어 플러그인이고 AList, rclone, FFmpeg 등은 관리되는 기반 서비스 또는 상류 서비스입니다. 프록시 호환 플러그인과 네이티브 플러그인은 같은 SDK 경계 뒤에서 독립적으로 발전할 수 있습니다.

## 비목표

CarMediaHub는 공용 무제한 대역폭 프록시, 필수 중앙 계정, 모든 상류 애플리케이션의 대체품이 아니며 모든 웹사이트나 장치와의 플러그인 호환을 보장하지 않습니다.
