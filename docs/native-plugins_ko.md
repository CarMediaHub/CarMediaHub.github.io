# 네이티브 미디어 플러그인

상태: v0 초안

네이티브 미디어 플러그인은 상류 웹사이트를 복제하지 않고 CarMediaHub 계약 안에서 제품 흐름을 구현합니다. WDR은 운영자가 관리하는 미디어를 제한된 차량 브라우저에 제공하고 Core가 저장소, 변환, 자격 증명과 재생 보안을 관리하는 참조 형태입니다.

## 책임 경계

플러그인은 사용자용 카탈로그 메타데이터, 탐색 의도, 재생 요청, 다국어 문구와 범위가 제한된 기록을 담당합니다. Core는 미디어 루트, probe, Range/HLS 세션, FFmpeg 작업, 결과 만료, 장치 컨텍스트, 권한과 진단을 담당합니다.

Worker는 불투명한 미디어 식별자와 제한된 capability 응답만 받습니다. 호스트 경로, WebDAV URL, FFmpeg 명령, 데이터베이스 연결, 브라우저 Profile 또는 재사용 가능한 공개 미디어 URL은 받지 않습니다.

## 차량 중심 동작

네이티브 미디어 플러그인은 디스플레이와 입력 capability를 협상하고 탐색과 전체 화면 동작을 유지하며 브라우저가 형식을 재생하지 못할 때 명확히 대체 상태를 보여야 합니다. 데스크톱 설정은 차량 화면보다 풍부할 수 있지만 동일한 Core 사용자와 locale 컨텍스트를 상속해야 합니다.

## 패키지와 데이터 규칙

실제로 사용하는 capability와 경로만 선언합니다. 기록과 플러그인 데이터는 SDK 범위 데이터 API로 저장하며 별도의 전역 언어 설정을 만들지 않습니다. staging 패키지에는 패키지 상대 Worker, 세 언어 README, migration, SBOM, digest와 서명이 필요합니다.

현재 WDR 패키지는 SDK 참조 예제이며 모든 AList/rclone 형식, 모바일 브라우저 또는 차량 모델과의 호환을 보장하지 않습니다.
