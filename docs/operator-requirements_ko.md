# 운영자 요구 사항

CarMediaHub는 중앙 릴레이 뒤에 인프라 요구 사항을 숨기지 않습니다. 운영자는 네트워크 경로, 저장소, 상위 서비스와 데이터 보존 정책을 책임집니다.

## 필수

- 지원되는 Core 런타임과 쓰기 가능한 데이터 디렉터리
- Core Gateway에 연결되는 안정적인 HTTPS 도메인
- 활성 데이터 디렉터리 밖에 보관한 백업
- 복구 절차가 있는 관리자 계정

## 권장

- 방화벽 뒤에서 Gateway를 실행하고 HTTPS만 공개합니다.
- 관리형 구성 요소마다 별도 서비스 계정을 사용합니다.
- 미디어 변환을 위한 대역폭을 확보하고 플러그인 리소스 제한을 설정합니다.
- liveness, readiness, 디스크 공간과 구성 요소 상태를 모니터링합니다.
- 깨끗한 디렉터리에서 복원을 시험한 후 백업을 사용 가능한 것으로 간주합니다.

## 책임 경계

Core는 ID, 범위, 권한과 네트워크 정책을 적용할 수 있지만 잘못 구성된 역방향 프록시, 인증서, 상위 계정 또는 저장소의 신뢰성을 보장할 수는 없습니다. 장애 보고에는 배포 대상과 구성 요소 버전을 기록하십시오.
