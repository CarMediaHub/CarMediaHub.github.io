# 自实现媒体插件

状态：v0 草案

自实现媒体插件在 CarMediaHub 契约内实现完整产品流程，而不是镜像某个上游网站。WDR 是参考形态：它把运营者控制的媒体呈现给能力受限的车机浏览器，同时由 Core 管理存储、转换、凭据和播放安全。

## 职责边界

插件负责面向用户的目录元数据、导航意图、播放请求、国际化文案和作用域历史。Core 负责媒体根目录、探测、Range/HLS 会话、FFmpeg 任务、输出过期、设备上下文、授权和诊断。

Worker 只接收不透明媒体标识和有界能力响应，不会接收宿主路径、WebDAV URL、FFmpeg 命令、数据库连接、浏览器 Profile 或可长期复用的公网媒体 URL。

## 车机导向行为

自实现媒体插件应协商显示和输入能力，保持导航和全屏操作可用，并在浏览器不支持某种格式时给出清晰的降级状态。桌面端配置可以比车机端更丰富，但两者必须继承同一个 Core 用户和语言上下文。

## 包和数据规则

只声明插件实际使用的能力和路由。历史和插件数据通过 SDK 的作用域数据 API 持久化，使用继承的语言和平台上下文，不另建全局偏好。进入 staging 的包必须提供包内相对 Worker、三语 README、迁移、SBOM、摘要和签名。

当前 WDR 包是 SDK 参考示例，不代表已经兼容所有 AList/rclone 格式、手机浏览器或车型。
