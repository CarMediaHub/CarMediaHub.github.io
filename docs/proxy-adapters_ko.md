# 프록시 호환 어댑터

상태: v0 초안

프록시 호환 어댑터는 운영자가 승인한 상류 사이트나 프로토콜의 호환 경계입니다. 범용 프록시를 배포할 수 있다는 뜻은 아닙니다. 상류 페이지, 스크립트, 리디렉션, Cookie, 미디어 호스트와 telemetry는 신뢰하지 않는 입력으로 취급합니다.

## 필수 경계

- 격리된 Worker와 선언된 최소 호스트 또는 서비스 바인딩을 사용합니다.
- 상대 경로와 선언된 메서드만 허용하며 리디렉션과 응답 제한은 Core가 관리합니다.
- Cookie와 Authorization은 Core의 자격 증명 참조 안에만 두며 Worker나 클라이언트에 평문을 반환하지 않습니다.
- CarMediaHub 경로를 우회하는 외부 탐색, 런타임 리소스 URL, telemetry, hotlink 검사와 미디어 호스트를 제거하거나 다시 작성합니다.
- 공개 배포 전 사이트별 누출 및 롤백 테스트가 필요합니다.

프록시 토큰, 패널 도메인, 로컬 주소, 브라우저 Profile, CDP 엔드포인트 또는 임의 상류 URL을 노출해서는 안 됩니다. 페이지가 열려도 브라우저가 외부 사이트에 직접 요청하면 계약 위반입니다.

## 공개 정책

현재 공개 카탈로그에는 중립적인 어댑터 예제와 로컬 서비스 브리지만 포함됩니다. `proxy-compat-contract-example`는 상대 경로 검증, 요청/응답 헤더 필터링, 리디렉션 억제와 응답 크기 제한을 보여 주며 실제 웹사이트를 지정하거나 연결하지 않습니다. BBC, YouTube, Jable, Pornhub 등의 기존 `site_gateway` 상류 어댑터는 권한, 누출, 호환성과 유지보수 검토가 끝날 때까지 비공개 마이그레이션 메타데이터로만 유지합니다. 폐기된 항목은 감사 기록일 뿐 공개 컬렉션에 복사하지 않습니다.

## 더 안전한 대안

운영자가 관리하는 AList, rclone, Mihomo에는 Core 서비스 바인딩을 우선 사용합니다. 제어된 재생에는 자체 미디어 플러그인을 우선하고, 브라우저 세션 계약은 Cookie, Profile, 임의 탐색과 스크립트 실행을 노출하지 않는 불투명하고 제한된 세션에만 사용합니다.
