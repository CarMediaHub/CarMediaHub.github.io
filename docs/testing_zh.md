# 测试与验证

状态：v0 草案

CarMediaHub 把测试视为契约证据。单元测试通过并不能证明某种部署、浏览器、上游网站或车机已经受支持，除非对应环境已经实际验证。

## 必测层次

1. SDK 契约测试覆盖清单校验、语言回退、上下文传递、Wire 方法白名单、作用域隔离、有界载荷、取消和内存运行时。
2. Core 测试覆盖身份、权限、持久化、插件生命周期、网关过滤、服务绑定、媒体 Range、任务、浏览器任务边界、备份完整性和显式配置。
3. Plugins 执行包契约测试、类型检查、构建、目录校验和隔离 Worker 集成测试。夹具不等于真实浏览器或上游网站测试。
4. 部署门禁校验已提交的 Docker 与 Native 规格，但不能据此声称本机已经注册系统服务。

## 发布证据

记录提交、包版本、平台、配置模式、组件摘要、命令、结果数量和已知限制。作用域拒绝、撤销、取消、超时、回滚、泄露和恢复等失败路径必须有测试。浏览器测试必须静音，不能使用宿主 Profile、任意 URL、CDP 地址或隐式环境变量。

当前仓库已有 SDK/Core/Plugins 契约层和部署静态门禁证据。真实 Windows 服务注册、Docker/NAS 安装、签名组件分发、真实 Browser Worker 导航以及桌面/手机/车机播放仍是独立发布门槛。
