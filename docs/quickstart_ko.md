# 사용자 빠른 시작

CarMediaHub는 사용자가 직접 운영하는 시스템입니다. 도메인, 서버, 저장소와 상위 서비스 계정은 운영자가 관리하고, Core는 미디어와 설치된 서비스를 위한 인증된 단일 웹 진입점을 제공합니다.

## 시작 전

- 대상 환경에 맞는 배포 방식을 선택하고 전용 데이터 디렉터리를 준비합니다.
- 도메인과 HTTPS 인증서를 준비합니다. 브라우저 기능은 등록된 HTTPS Origin만 허용합니다.
- 사용할 사용자, 미디어 루트와 플러그인을 먼저 결정합니다.

## 최초 실행

1. 대상 환경의 릴리스 안내에 따라 Core를 설치합니다.
2. 초기화 안내를 완료하고 첫 번째 관리자를 만듭니다.
3. 관리 화면에서 언어, 시간대, 보안과 백업 설정을 확인합니다.
4. 필요한 플러그인과 관리형 기본 구성 요소만 설치합니다.
5. 미디어 루트나 원격 소스를 추가하고 작은 파일부터 확인합니다.
6. 데스크톱 브라우저와 차량 브라우저에서 같은 진입점을 확인합니다. 차량 재생은 미디어 기능에 따라 HLS 또는 리먹스 스트림을 선택할 수 있습니다.

## 보안 경계

보호된 자격 증명 흐름이 문서에 명시되지 않았다면 Cookie, 브라우저 Profile, 개인 키 또는 상위 서비스 비밀번호를 플러그인 설정에 붙여 넣지 마십시오. Core, 플러그인과 구성 요소 패키지를 최신 상태로 유지하고 업그레이드 전에 검증 가능한 백업을 만드십시오.
