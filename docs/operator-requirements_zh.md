# 运维前置条件

CarMediaHub 不通过中央中继隐藏基础设施要求。运营者负责网络链路、存储、上游服务和数据保留策略。

## 必需条件

- 受支持的 Core 运行时和可写数据目录。
- 能够访问 Core Gateway 的稳定 HTTPS 域名。
- 存放在活动数据目录之外的备份。
- 具备恢复流程的管理员账号。

## 建议条件

- 在防火墙后运行 Gateway，只暴露 HTTPS。
- 为每个受管组件使用独立服务账号。
- 为媒体转换预留带宽，并为插件设置资源限制。
- 监控存活、就绪、磁盘空间和组件健康状态。
- 在全新目录中演练恢复，再把备份视为可用。

## 责任边界

Core 可以执行身份、作用域、能力和网络策略，但无法替错误配置的反向代理、证书、上游账号或存储服务保证可靠性。每次故障记录都应包含部署目标和组件版本。
