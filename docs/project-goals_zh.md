# 项目目标

状态：v0 草案

CarMediaHub 的目标是让运营者控制的媒体、内网服务和可扩展适配器能够被浏览器和车载显示屏使用，同时不把项目变成必须依赖的托管中继。

## 用户结果

- 在受限的车机浏览器中访问个人媒体。
- 适配存储和上游服务，不必暴露所有内网端口。
- 通过统一入口获得认证、历史、任务和诊断能力。
- 安装或开发能够继承平台上下文、语言、身份和能力控制的插件。
- 域名、服务器、带宽、数据和上游账号继续由运营者控制。

## 统一 Web 界面

CarMediaHub 是一套统一 Web 服务，而不是互不关联的网站集合。面板可以提供常规应用导航，也可以为指定应用配置可撤销的 Key 入口。内置管理端在面板中与插件并列展示，但复杂配置仍由运营者负责。

电脑浏览器主要用于安装、权限、服务连接、会话导入、备份和升级；手机提供响应式浏览和轻量设置；车机优先提供简单导航、搜索、播放、全屏和便于恢复的状态提示。

## 平台目标

Core、Gateway、SDK、服务绑定和运行时隔离是长期平台能力。WDR 是重要的自实现媒体插件，AList、rclone、FFmpeg 等属于受管理的基础服务或上游服务。代理兼容插件和自实现插件可以在同一 SDK 边界后独立演进。

## 非目标

CarMediaHub 不是公共无限流量代理、强制中心账号、所有上游应用的替代品，也不承诺任意插件兼容所有网站或设备。
