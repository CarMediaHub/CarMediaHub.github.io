# 插件发布

状态：v0 草案

发布是可复现的打包操作，不是自动批准。包必须从干净检出、版本化 SDK、包内相对入口、本地化资源、许可证、校验和、SBOM 和签名发布记录构建。

## 包门禁

- 按 SDK 版本校验清单和声明的能力。
- 构建 Worker 或受信共享适配器，不能包含宿主路径或未经校验的下载可执行文件。
- 执行类型、契约、隔离、泄露、回滚和目录测试。
- 使用受信发布密钥生成包摘要、SBOM、provenance 元数据和签名。
- 只发布包和公开文档；凭据、Profile、日志和私有部署数据不得进入包。

目录记录发布者、许可证、SDK 范围、运行时、目标类别、风险、数据生命周期、支持状态、摘要和撤销状态。目录条目不证明上游网站可用。浏览器、外部网络、媒体提取和代理兼容插件在公开分发前必须通过额外评审。
