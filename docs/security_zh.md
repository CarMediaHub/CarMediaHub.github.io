# 安全模型

状态：v0 草案

CarMediaHub 采用 capability-first 模型。插件只获得其安装实例获准的最小作用域句柄。Core 在每个受保护边界验证身份、策略、目标、作用域、资源限制、取消和审计状态。

## 默认规则

- 插件不拥有公网宿主端口。
- 插件不获得原始数据库连接字符串或管理员凭据。
- 插件不获得不受限制的文件系统、Shell、网络或浏览器 Profile 访问。
- 插件之间不隐式共享配置、数据、缓存、秘密、日志、任务或浏览器状态。
- 已安装部署运行不要求托管账号、中继或中心服务。

## Web 响应安全

Core 统一入口对所有响应设置内容类型嗅探、跨来源引用、浏览器能力和嵌入限制；Core 自有页面和 API 还使用同源内容安全策略。插件 `/apps/*` 内容由插件自身负责资源策略，Core 不强行覆盖其页面内容。

## 受管组件

受管组件二进制文件先进入部署内部的 staging 目录，Core 不通过宿主 PATH 发现它们。安装要求发布记录由运营者信任的 Ed25519 密钥签名；记录绑定组件、版本、平台、artifact 标识和 SHA-256 摘要。任一字段或签名与 staging 文件不匹配都会被拒绝。下载源、密钥轮换、健康检查和回滚仍属于部署运维能力，不属于插件能力。

Core 启动受管组件前会重新校验登记的 SHA-256 摘要，并使用 `shell:false` 运行已验证的绝对文件。组件参数、执行时间、取消和 stdout/stderr 合计大小均有界。插件不能选择命令、可执行路径、环境变量或任意组件参数。

## 受管理媒体根目录

每个媒体根目录必须由管理员显式选择。Core 在部署数据中加密保存所选路径，并在访问时校验目录和文件类型、忽略符号链接；API 只暴露根 ID 与不透明媒体 ID，插件不会获得宿主路径。受控递归索引、短期播放会话、Range 读取、Core 管理的转封装/转码任务、短期作用域绑定的转换结果读取及认证播放路由已提供；过期结果会在 Core 启动时清理。永久结果 URL、缩略图、HLS 和跨重启缓存恢复目前尚未提供。

## 插件发布物

安装隔离 Worker 要求插件包发布记录由运营者信任的 Ed25519 密钥签名。签名绑定 Manifest、签名者标识、staging artifact 标识和规范目录摘要。Core 只安装相匹配的 staging 目录，拒绝链接与不安全入口，并且仅保存用于重启恢复的相对验证包位置。包验证不同于能力授权或启动 Worker；媒体 Range、有界的 Core 转封装/转码执行和带认证的短期结果播放已提供，但永久结果 URL、HLS、升级与回滚目前尚未提供。

## 运营者责任

运营者控制管理端访问、用户账号、设备、公网入口、网络路径、存储、备份和插件授权。任何可选外部服务都必须说明哪些数据离开运营者控制的基础设施以及原因。

## 报告

安全报告应包含最小复现、受影响版本和影响描述。不得包含密码、恢复码、私钥、会话数据、浏览器 Profile、完整请求日志、个人媒体或机密 URL。
