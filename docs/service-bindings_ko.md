# 서비스 바인딩

상태: v0 초안

서비스 바인딩을 사용하면 플러그인이 CarMediaHub의 단일 진입점을 통해 운영자가 관리하는 로컬 서비스를 사용할 수 있습니다. 플러그인은 범위가 제한된 클라이언트만 받고 원시 소켓, 데이터베이스 연결, 호스트 경로 또는 공개 포트를 받지 않습니다.

## 계약

운영자는 설치된 플러그인 인스턴스에 바인딩을 생성합니다. Core는 내부 엔드포인트와 자격 증명을 보관하고 선언된 바인딩 이름을 확인하며 출처, 메서드, 리디렉션, 본문 크기, 응답 크기, 동시성, 시간 초과와 취소 제한을 적용합니다.

플러그인은 `network.request`로 상대 경로와 제한된 요청 데이터만 제출할 수 있습니다. 임의 URL, 호스트명, 포트, Cookie, Authorization, 셸 명령 또는 파일 시스템 경로는 제출할 수 없습니다. 바인딩 상태 확인은 Core가 제한적으로 수행하며 플러그인에 네트워크 권한을 부여하지 않습니다.

## 기본 서비스 역할

| 역할 | 예시 서비스 | 경계 |
|---|---|---|
| `storage` / `webdav` | AList 또는 rclone | Core가 관리하는 미디어 소스 또는 제한된 관리 브리지 |
| `media-processing` | FFmpeg | Core가 관리하는 probe, remux, transcode 및 VOD HLS 작업 |
| `network-egress` | Mihomo | 운영자 정책과 제한된 제어 API 접근 |
| `archive` | 7z 호환 구성 요소 | Core가 관리하는 보관 작업, 플러그인 명령 실행 아님 |

이는 호환성 역할이며 모든 플랫폼에 바이너리가 포함된다는 뜻이 아닙니다. 설치, 서명, digest, 상태 확인과 플랫폼 지원은 별도의 게이트입니다.

## 예시와 제한

`alist-web-bridge`와 `mihomo-web-bridge`는 참조 어댑터입니다. 선언된 상대 경로와 필터링된 헤더만 전달하며 상류 소스 코드를 수정하지 않고 자격 증명을 노출하지 않습니다. AList WebDAV나 Clash Web UI 전체 호환을 보장하지도 않습니다.

원격 WebDAV 미디어 소스는 AList 관리 브리지와 별도의 기능입니다. Core가 소스 핸들, 자격 증명 주입, 목록, probe, 재생 세션과 Range 읽기를 관리합니다. 초기 계약에는 쓰기, 삭제, 업로드, 임의 프록시와 LAN 자동 검색이 포함되지 않습니다.
