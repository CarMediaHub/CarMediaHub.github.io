# Docker 배포

상태: v0 Draft

Docker 배포는 Core Gateway 하나만 외부에 공개합니다. Core, 내부 런타임 채널 및 선택적 기본 서비스는 내부 네트워크에 두며 데이터베이스, Worker, 플러그인 또는 디버그 포트를 공개하지 않습니다.

## 현재 계약

명시적인 JSON 설정 파일과 전용 영구 데이터 디렉터리를 사용하고 배포 계약에 선언된 디렉터리만 마운트합니다. Core는 `.env`, `PATH`, `PG*`, 호스트 브라우저 프로필 또는 임의의 호스트 경로를 탐색하지 않습니다. 자격 증명은 배포 측 비밀 관리 기능에 보관하며 플러그인에는 원시 데이터베이스 연결을 제공하지 않습니다.

저장소 CI는 강화된 이미지를 빌드하고 Linux 컨테이너에서 `/health/live`와 `/health/ready`를 확인합니다. 소스 저장소는 모든 호스트에 Docker가 설치되어 있다고 보장하지 않습니다. 외부에 공개하기 전에 이미지 출처, 저장소 권한, HTTPS 종료, 백업/복구 및 미디어 작업의 자원 제한을 확인해야 합니다.

이미지는 전용 비 root 사용자 `carmediahub`로 Core를 실행합니다. 기본 Compose 프로필에서는 관리 데이터 볼륨만 쓰기 가능하며 이미지 파일 시스템은 읽기 전용입니다.

## 네트워크와 업그레이드

리버스 프록시는 설정된 Gateway 포트만 전달합니다. PostgreSQL, 서비스 바인딩, Worker IPC 및 관리 컴포넌트 포트는 내부에 유지합니다. 오프라인 SQLite 스냅샷 전에는 서비스를 중지하거나 배출하고, 빈 데이터 디렉터리에 복구하기 전에 스냅샷을 검증합니다. 컴포넌트 업데이트는 스테이징과 정상 상태 확인 후 활성화하며, 확인 실패 시 현재 활성 버전을 바꾸지 않습니다.

## 아직 릴리스 약속이 아닌 항목

깨끗한 호스트의 Docker 설치, 운영용 Compose 기본값, 실제 AList/rclone/FFmpeg/Mihomo 이미지, 온라인 백업, 호스트 간 복구 및 전체 Docker 업그레이드/롤백 리허설은 아직 릴리스 게이트입니다. CI 증거는 운영자의 실제 리허설을 대신하지 않습니다.
